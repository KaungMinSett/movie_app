# Movie Explorer

A  React application for exploring movies, powered by the [TMDB API](https://www.themoviedb.org/documentation/api) and [Appwrite](https://appwrite.io/) for data management. Styled with Tailwind CSS and hosted on [Vercel](https://kms-movie-app.vercel.app/).


## Features
- **Browse All Movies**: Discover a wide variety of movies available on the platform.
- **Search Movies**: Quickly find specific movies with an intuitive search function.
- **Trending Movies Algorithm**: View trending movies driven by a dynamic algorithm.

## Tech Stack
- **Frontend**: React, Vite
- **Styling**: Tailwind CSS
- **Backend-as-a-Service**: Appwrite
- **API**: TMDB API


## Prerequisites
- Node.js (v16 or higher)
- A TMDB API key ([get one here](https://www.themoviedb.org/settings/api))
- An Appwrite project ([set up here](https://appwrite.io/docs/quick-starts))
